## 本次修改

- 转接板的容量参考为沿屏面的36×30mm、厚4mm，随屏幕倾斜放在屏背空间。该值是设计容量，尚无转接板实测尺寸。
- 屏幕前框和玻璃定位沿用V2；前框STL与V2几何相同。
- 组件 d=97沿左右，e=34沿前后，f=38竖直；相对V2后移2mm，为屏背薄板留余量。
- 组件下方3mm安装高度、平顶净空约2.8mm保留。
- 取消转接板后仓，组件后侧仅留7.5mm用于螺丝柱及装配。后螺丝柱外径6mm，后限位条避让螺丝柱。
- 充电缺口随组件位置平移，仍在左侧且沿e的中央，沿前后宽29mm，从外部底边向上14mm。插头伸入内部时要考虑3mm底盖占用。
- 转接板和屏幕、驱动板之间分两段预留走线，实际线长、插头方向和柔性排线的弯曲仍需试装。

## 装配

1. 清理支撑、毛刺，先不装前框和底盖。
2. 屏幕玻璃91×76.5mm从前面放进后壳浅座，FPC穿下方通道。用户屏厚估计0.95～1.0mm，模型检查按1.2mm参考。薄软垫仅放在非显示边缘，按实际厚度调整，不硬夹玻璃。
3. 四颗3×8mm盘头塑料自攻螺丝轻锁前框。
4. 蓝色转接板随屏面倾斜布置在屏背空余区域，采用绝缘软垫/胶固定在后壳内表面，不让它顶压玻璃。连接屏幕FPC，留出接口和排线余量。
5. 电池、电源和驱动板保持现有组合，在底盖上横放，97mm长边平行屏幕宽边，充电口朝左。用绝缘软垫在可靠支撑面固定，3mm为预留安装高度，避开PCB元件焊点。
6. 延长线由转接板通往组件，按内部空隙自然弯曲收纳。装底盖前用实际Type-C线试插开口，确认板件和线缆均不受挤压。
7. 底盖及组件从下方放入，四颗3×10mm沉头塑料自攻螺丝固定。底孔2.5mm、通孔3.4mm，打印商家需确认螺丝适配。
8. 可贴8mm脚垫四个。底盖用于装配和检修，无独立电池仓盖；检修前断电并释放排线余量。
