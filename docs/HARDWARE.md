# 硬件详解

| 项目 | 内容 |
| --- | --- |
| 驱动板 | Waveshare e-Paper ESP32 Driver Board Rev 3：ESP32-WROOM-32E、Type-C、CH343P、24pin FPC |
| 芯片 | ESP32-D0WD-V3 rev3.1，4MiB Flash，无 PSRAM（固件不依赖） |
| 屏幕 | HINK-E042A03-A1，4.2 英寸 400×300 黑白，24pin；按 SSD1619A 资料适配；仅全刷，完成后休眠 |
| 备选屏 | 微雪 4.2inch e-Paper V2（SKU 13186），改 `ClockConfig.h` 里 `CLOCK_HINK_FULL_REFRESH_ONLY` 为 0（局刷 / 15 分钟全刷）。换屏务必重新核对型号 |
| 拨码开关 | 1 号 B（3Ω）、2 号 ON；调整前断电 |
| 电源 | 18650 电池模块（3.7V / 5V / 3.3V，5V 最大约 2A，Type-C 只充电，按键开机，长按 10 秒关机）；5V、GND 用杜邦线接驱动板排针；也可以 USB 供电 |
| USB | Type-C 数据线，115200 日志；COM 口不是固定身份，每次烧录前重新确认 |
| 外壳 | `enclosure/` 三件：前框 105×90.5×2.4、后壳 105×65.9×94.52、底盖 99.6×56.9×9（mm）；屏座、孔与排线通道需去毛刺；玻璃只在非显示边缘软垫支撑，不硬压 |

## 屏幕引脚（`firmware/src/waveshare/DEV_Config.h`）

SCK 13 · MOSI 14 · CS 15 · RST 26 · DC 27 · BUSY 25；BOOT = GPIO0（短按切页）。

## Flash 分区（4MiB，`firmware/partitions.csv`）

| 名称 | 偏移 | 大小 |
| --- | --- | --- |
| nvs | 0x9000 | 0x5000 |
| otadata | 0xE000 | 0x2000 |
| app0 | 0x10000 | 0x1C0000 |
| app1 | 0x1D0000 | 0x1C0000 |
| spiffs（照片 / 心情缓存） | 0x390000 | 0x70000 |

当前最终版 7.1.0 应用约 1,440,192 字节，单个 OTA 槽 1,835,008 字节，余量有限，加功能前先看体积。

## 屏幕数据格式

400×300，1bit/像素，每帧 15000 字节，行优先、高位在前、1 = 白。相册上限 20 张；心情是两个 200×300 半屏。

## 屏幕适配原则

不同屏幕分别确认支持的刷新方式、间隔、初始化 / 休眠时序和 BUSY 响应；显示刷新与数据查询频率分开配置。BUSY 超过 20 秒视为故障，保持复位并停止发图。
