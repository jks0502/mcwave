# mcwave 固件版本更新历史

版本号规则（2026-10-21 起）：`大.中.小`——大＝改分区或只能有线升级；中＝新功能；小＝修复或小调整。设备上报字符串带 `V`（如 `V7.1.0`）。10-21 之前的 `V1.0–V5.4` 是旧写法，不重新编号。

## 第一阶段：天气 + 赛事摆件（V1.0–V4.8，2026-10-03 → 10-19）

| 版本 | 干嘛的 |
| --- | --- |
| V1.0–V2.3 | 天气桌面小钟：联网取天气，画天气页和形象图 |
| V2.4 | 每分钟独立随机换一张形象图 |
| V3.0 | 新增紧凑两列赛事页，每页 8 场，今日在前；BOOT 短按切页、长按翻页 |
| V3.1 | 改用国内公开数据源直连（中国天气网、腾讯体育、5E），不再依赖境外聚合接口，修热点下加载失败 |
| V3.2 | 天气失败时保留旧数据；赛事每分钟查询 |
| V3.3 | 修赛事解析因 40KB 临时缓冲分配失败而停在旧时间 |
| V3.4 | 修网络读取占满 CPU 触发看门狗重启；天气赛事断电缓存 |
| V3.5 | SEU 校园网网页自动认证、每分钟检查、失效重登 |
| V3.6 | 校园网名称改为区分大小写的 `SEU-WLAN`，启动扫描日志 |
| V3.7 | 针对 HINK 屏改成"全刷后休眠"，自动刷屏至少间隔 1 分钟 |
| V3.8–V3.9 | 赛事去重：同场比赛不同 ID、主客队互换、各项目统一规则 |
| V3.10 | 下次降雨时点 + 同小时概率（中央气象台 + 中国天气通，免 Token） |
| V3.11 | 降雨时间改成"今天约 18 时 / 明天约 02 时 / 4 天后"，按北京时间日历算 |
| V4.0 | 接入个人网站：网页远程选天气 / 赛事、翻页；设备主动 HTTPS，适配校园网 |
| V4.1 | 赛事筛选与补足：关注比赛全保留，不足 16 / 8 场按热门球队补充 |
| V4.2 | 天气页文字统一 13px Noto Sans SC，预报行对齐 |
| V4.3 | HTTP 正文共用固定 1KB 接收缓冲，省内存 |
| V4.4 | 天气与赛事 JSON 共用工作区，修 DNS 缓存清理缺锁的启动断言 |
| V4.5 | 赛事 JSON 一次分配直接生成 |
| V4.6 | 语录 10000 句缩到 100 句，程序瘦约 588KB |
| V4.7 | 字形表二分查找，布局不变 |
| V4.8 | 赛事按赛况调整查询间隔（有比赛进行每分钟，否则半小时） |
